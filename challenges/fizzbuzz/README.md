# FizzBuzz

Implement `fizzbuzz(limit: u32) -> Vec<String>`.

Return the values from 1 through `limit`. Multiples of 3 become `Fizz`, multiples of 5 become `Buzz`, and multiples of both become `FizzBuzz`. Other values use their decimal representation. A limit of zero returns an empty vector.

## Requirements

- Use fewer than 2 loops.
- Do not clone values.
