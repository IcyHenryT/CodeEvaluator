# Leaderboard

Implement `leaderboard(scores: Vec<PlayerScore>) -> Vec<LeaderboardEntry>`.

Sort players from highest score to lowest and assign sequential one-based ranks. Players with tied scores must keep their original input order, but still receive distinct ranks. Correctly handle negative scores and the full `i64` range.

## Requirements

- Do not use loops or clone calls.
- Player names may be moved from the input.
