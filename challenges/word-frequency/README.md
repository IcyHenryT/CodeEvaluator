# Word Frequency

Implement `word_frequency(text: &str) -> HashMap<String, usize>`.

Return a case-insensitive frequency map. Words are consecutive Unicode alphanumeric characters; punctuation, whitespace, apostrophes, and hyphens act as separators. Include digits and use Unicode-aware lowercase conversion.

## Requirements

- Use at least 1 and fewer than 3 loops.
- Do not clone values.
