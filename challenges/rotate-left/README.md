# Rotate Left

Implement `rotate_left<T>(values: Vec<T>, amount: usize) -> Vec<T>`.

Rotate the vector left by `amount` positions, wrapping elements from the front to the back. Oversized amounts wrap by the vector length. Empty vectors must not panic, and non-`Copy` values must be supported without a `Clone` bound.

## Requirements

- Do not use loops or clone calls.
