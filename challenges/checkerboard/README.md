# Checkerboard

Implement `checker_board(x: u64, y: u64) -> Vec<Vec<bool>>`.

Return a checkerboard with `x` rows and `y` columns. The top-left cell must be `true`, and every horizontally or vertically adjacent cell must alternate between `true` and `false`. Zero rows returns an empty vector; zero columns returns `x` empty rows.

## Requirements

- Use fewer than 3 loops.
- Use fewer than 3 clone calls.
